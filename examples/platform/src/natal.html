Local draft JSON export and import

A full export includes the birth instant, coordinates, calculation result, and any retained optional data. Export only when you intend to save those details in a local file. Imported files remain unverified claims; this Zodiacs draft is not an industry standard.

Import displays the stored receipt and result without changing the birth form or recalculating. Optional extensions are preserved for re-export and are not displayed. No file is uploaded or added to an account.

The diagnostic omits dates, coordinates, results, and arbitrary imported data. It is redacted, not anonymous; remaining time-known, house, and flag categories can still disclose context.
