Astrofolio SDK

Build Astrofolio-like astrology interfaces.

Astrofolio is a related experience around personal Zodiac shelves and symbolic ownership. Zodiacs SDK is the developer interface for building those patterns with verified Zodiac ownership.

What developers can build.

  • Personal Zodiac shelves.
  • Cosmic Receipts and share cards.
  • Public profiles with held-sign context.
  • Compatibility surfaces that include held signs.
  • AI astrology context for Astrofolio-like interfaces.
