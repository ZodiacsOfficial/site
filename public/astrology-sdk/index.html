Astrology SDK

An ownership layer for astrology apps.

Zodiacs SDK is the official read-only TypeScript SDK for building astrology apps with verified Zodiac ownership.

Verify

Official Zodiacs

Recognize official Zodiac representations across Solana and Base.

Read

Public ownership

Read public held-sign context without custody, signing, or transactions.

Compose

Identity context

Turn held signs into wheel coverage, element mix, seasonal relevance, and profile facts.

Render

Astrology surfaces

Build Zodiac shelves, Cosmic Receipts, AI astrology context, and app-ready icon surfaces.

Where it fits.

Birth chart tools calculate natal placements. Ephemeris libraries calculate sky positions. Zodiacs SDK adds a different input: the signs a person chooses to carry.
