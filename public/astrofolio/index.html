Related experience

Astrofolio and Zodiacs SDK.

Astrofolio is a related experience around personal Zodiac shelves and symbolic ownership. Zodiacs.org is the official registry and SDK source of truth.

The canonical Astrofolio website is astrofolio.xyz.

Apps, including Astrofolio-like experiences, should use Zodiacs SDK for verified ownership, public reads, identity context, symbolic resonance, and icon assets.

Developer source of truth.

Zodiacs SDK is the official read-only TypeScript SDK for building astrology apps with verified Zodiac ownership. It recognizes official Zodiacs, reads public ownership, computes identity context, supports app-side symbolic resonance patterns, and exposes official icon assets.

Official registry. Public reads. No custody. No signing. No transactions.

The consumer surfaces.

Around the registry, Astrofolio maintains consumer experiences for the Twelve: the main app, a multi-buy tool, a shop for physical goods, and a public Dex Screener watchlist of the official pairs.
