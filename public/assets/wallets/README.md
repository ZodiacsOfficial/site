# Chain marks

Official brand symbols, self-hosted for the Registry Aura wallet buttons
(the aura route's CSP allows no third-party hosts). Used nominatively to
identify the networks; monochrome variants per each brand's kit.

- `base-mark.svg` — "The Square", white digital variant, from the official
  Base brand kit: https://github.com/base/brand-kit (fetched 2026-07-17).
- `solana-mark.svg` — Solana logomark from https://solana.com/branding
  (fetched 2026-07-17), recolored to the site ink `#EEF1F7` matching the
  kit's solid monochrome treatment (the site never renders gradients).

Wallet buttons in the picker use the icon each wallet announces about
itself (Wallet Standard `wallet.icon` / EIP-6963 `info.icon` data URIs),
never bundled copies, so the marks are always the wallets' own.
