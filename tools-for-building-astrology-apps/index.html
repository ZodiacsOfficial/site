Where Zodiacs SDK fits.

Birth charts show one kind of symbolic context. Zodiacs SDK adds another: verified signs that appear in a connected wallet. The SDK lets apps recognize official Zodiacs, read public ownership, and turn held signs into deterministic astrology context.

  • Use it for Zodiac shelves, identity receipts, public profiles, and chart overlays.
  • Use it when building Astrofolio-like astrology interfaces around personal Zodiac shelves.
  • Use it to give AI astrology products verified held-sign context.
  • Use it for symbolic resonance patterns such as aura bars, hover text, and share cards.
  • Use it for Simastry-like Aura pages that can be shared and can inform AI astrologist conversations.
