Provider unavailable — an honest 503, and nobody gets stranded

The blockchain data provider failed or timed out. The endpoint already refuses to invent an answer (partial data never becomes a false absence); the V3 change is purely experiential: the error keeps the retry path and adds a visible example escape, which the current implementation hides once an address is filled in. Audit §3 #16, §11.
