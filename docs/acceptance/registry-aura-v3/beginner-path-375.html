New to crypto?

Wallets, without the jargon

A wallet is an app or device that manages a blockchain account. Registry Aura only needs one public address—the shareable identifier used to look up its public record.

2
Aura never needs your wallet secrets.

Never type a recovery phrase, private key, wallet password, or PIN into Registry Aura. Aura never asks you to sign a message, approve or send a transaction, swap an asset, or switch networks. If a wallet prompt asks for any of those while using Aura, cancel it.
